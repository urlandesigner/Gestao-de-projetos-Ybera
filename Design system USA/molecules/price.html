Price

O preço de um produto, com o valor anterior riscado e o desconto quando existem. Sempre tabular: em grid, dígitos precisam alinhar em coluna.

  • Classe base .yb-price

Anatomia e API

$168.90$199.90Save $31
  1. Preço — Agrupa o que se paga, o que se pagava e o quanto se economiza.
  2. Agora — O que se paga. É sempre o mais pesado da linha.
  3. Antes — <s>, riscado. Só aparece quando existe de verdade.
  4. Economia — Opcional. É o .yb-badge, outra peça, com o valor poupado.

De que a peça é feita, o que ela aceita e os tokens que consome — estes do mais específico desta peça para o mais compartilhado com o resto do sistema. Tudo lido da folha de estilo e do HTML a cada build: se estiver errado aqui, o errado é o código.

Faça / não faça

✓ Faça

$74.90$89.90Save 16%

Preço antigo em <s> e o desconto escrito.

✕ Não faça

$74.90$89.90

Risco só no CSS: para o leitor de tela os dois preços têm o mesmo peso, e o de cima parece o que se paga.

Acessibilidade

  • O preço antigo vai em <s>, não em text-decoration aplicada a um span. O elemento diz “isto não vale mais”; o estilo só desenha.
  • Preço isolado usa proportional-nums: com tabular-nums o ponto ganha largura de dígito e “$149.90” lê como “$149 . 90”.
  • Quando há desconto, o quanto se economiza está escrito ao lado — dois números riscados não são uma conta que todo mundo faz de cabeça.
