Architecture

Os tokens são organizados em três níveis, e cada um usa o anterior. Os componentes usam só o nível do meio: os tokens com nome de uso, como --yb-action-primary-bg.

Camada 0 · Primitivos

Os valores puros: cada cor, tamanho e medida do sistema. Nenhum componente usa direto.

--yb-gray-950: #1E1E1F;
--yb-magenta-600: #CA235F;

Camada 1 · Semânticos

O nome de uso de cada valor, como “fundo do botão principal”. É o que os componentes usam, e o que você deve usar ao criar algo novo.

--yb-action-primary-bg:
  var(--yb-gray-950);
--yb-accent-signal:
  var(--yb-magenta-600);

Camada 2 · Componente

Ajuste de um componente específico, quando ele precisa fugir do padrão.

.yb-card{
  --yb-card-title-lines: 2;
}

E a diferença entre países? Se a loja dos EUA e a do Brasil precisarem de um visual diferente, a troca entra em [data-market="br"], por cima da camada 1. Hoje esse lugar está vazio: as duas usam os mesmos valores.
