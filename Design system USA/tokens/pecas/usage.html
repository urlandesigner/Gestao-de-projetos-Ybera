How to use

Um link, e os tokens ficam disponíveis em qualquer plataforma.

<link rel="stylesheet" href="ybera-tokens.css">
<html data-market="us">

.meu-botao {
  background: var(--yb-action-bg);
  color: var(--yb-action-text);
  border-radius: var(--yb-radius-control);
  padding: var(--yb-space-4) var(--yb-space-6);
  font-size: var(--yb-type-body-size);
  transition: background var(--yb-transition-control);
}
A regra que sustenta o sistema

Componente nunca consome a camada 0. Se você escreveu var(--yb-magenta-600) num componente, ou falta um token semântico ou o componente está errado. Nos dois casos, a correção é na camada 1.
