Architecture

Três camadas mais uma de mercado. A regra é simples: componente só enxerga a camada 1.

Camada 0 · Primitivos

Vocabulário bruto. Nenhum componente consome isto direto.

--yb-gray-950: #1E1E1F;
--yb-magenta-600: #CA235F;

Camada 1 · Semânticos

A intenção. A única camada que componentes consomem e que alguém precisa ler para entender o sistema.

--yb-text-primary: var(--yb-gray-950);
--yb-action-bg: var(--yb-magenta-600);

Camada 2 · Componente

Só onde há desvio local. Cada desvio fica visível e auditável.

.yb-card{ --yb-card-title-lines: 2; }

Camada de mercado

Aqui não se troca identidade — e hoje não se troca nada: o seletor existe vazio, de propósito (ver a nota em 01-semantic.css).

[data-market="br"] { }
