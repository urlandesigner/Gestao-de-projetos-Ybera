How to use

Baixe o pacote no Download do topo e descompacte no projeto: tokens, componentes e ícones vêm juntos, e o HTML de cada peça está na aba Código da ficha.

O que vem no pacote

Oito arquivos. Quatro você liga no passo 1, o README.txt repete a ordem, e sobram três que ninguém explica se esta página não explicar:

ybera-icons.svg
O sprite. Não entra no <head>: é o arquivo que cada <use href> vai buscar, e por isso precisa ficar ao lado dos outros. Sumiu daqui, some o ícone de toda a tela.
ybera-tokens.json
Os mesmos tokens em formato W3C (DTCG), derivados do CSS a cada build. São para quem não lê CSS — Figma Variables, Style Dictionary, tema nativo. Em projeto web, você não precisa dele.
ybera-bridge.css
Só para o tema Shopify atual da ybera.us: traduz os tokens para as variáveis que o tema, o Ecomposer e o Judge.me já expõem lá. Em qualquer outro projeto, ignore — e não o use de exemplo, porque ele é a única peça autorizada a consumir cor da camada 0.

1 · Ligue os arquivos, nesta ordem

O zip vem plano, sem pasta dentro: os caminhos abaixo supõem que você descompactou numa pasta ybera/ do projeto. Descompactado solto na raiz, tire o ybera/ dos cinco endereços — ou os cinco dão 404 e a página abre sem estilo nenhum.

A fonte não vem no pacote; sem ela, a página cai na fonte do sistema.

<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Schibsted+Grotesk:wght@400;500;600;700;800&display=swap">
<link rel="stylesheet" href="ybera/ybera-tokens.css">
<link rel="stylesheet" href="ybera/ybera-components.css">
<link rel="stylesheet" href="ybera/ybera-icons.css">
<script src="ybera/ybera-components.js" defer></script>

2 · Monte com o HTML das fichas

Copie da aba Código. O comportamento (gaveta, modal, toast, galeria, trilho) liga sozinho pelos atributos data-yb-*; conteúdo que entra depois do carregamento pede window.Ybera.init(elemento).

<button type="button" class="yb-btn yb-btn--primary">Add to cart</button>
<svg class="yb-icon" aria-hidden="true"><use href="ybera/ybera-icons.svg#yb-cart"/></svg>

3 · Sirva por HTTP

Aberta como arquivo (file://), a página perde os ícones: o navegador bloqueia o sprite externo.

python3 -m http.server 8080

O que o script expõe

Quase tudo liga sozinho pelos atributos data-yb-*, e é assim que as fichas mostram. O window.Ybera existe para os três casos em que atributo não resolve:

Ybera.init(raiz)
Religa tudo o que o script liga, dentro de um pedaço de DOM que chegou depois — seção carregada pelo tema, resultado de busca, carrinho que voltou do servidor. Idempotente: o que já está ligado leva data-yb-bound e é pulado, então chamar duas vezes não duplica nada.
Ybera.toast({ title, text, variant, duration })
Levanta um toast de código, para quando o aviso nasce de uma resposta e não de um clique. variant aceita success, warning, danger e info; sem ela, o neutro. Some em 5s, e duration: 0 o mantém até alguém fechar — é esse o único caso que ganha o × (Toast).
Ybera.openDialog(id, gatilho)
Abre o Modal daquele id. O gatilho é para onde o foco volta quando fechar; sem ele, volta para o que estava focado na hora.

O chão da tela

Página de loja tem chão branco (--yb-bg-page), e ali quem separa um cartão da página é a foto dentro dele.

Tela feita de painéis de texto não tem foto, e branco sobre branco some. Nessa tela o chão é --yb-bg-subtle e o conteúdo vai dentro do Panel com --flat. Com chão branco, o Panel sem modificador: ele traz fio e elevação, que é o que o faz existir.

<!-- chão branco -->
<div class="yb-panel">…</div>

<!-- chão --yb-bg-subtle -->
<div class="yb-panel yb-panel--flat">…</div>

Peça própria, com os tokens

Quando o sistema não tem a peça, use os tokens semânticos, nunca o valor.

.meu-botao {
  background: var(--yb-action-primary-bg);
  color: var(--yb-action-primary-text);
  border-radius: var(--yb-radius-control);
  padding: var(--yb-space-4) var(--yb-space-6);
  font-size: var(--yb-type-body-size);
  transition: background var(--yb-transition-control);
}
A regra que sustenta o sistema

Componente nunca consome cor da camada 0. Se você escreveu var(--yb-magenta-600) num componente, ou falta um token semântico ou o componente está errado. Nos dois casos, a correção é na camada 1.

Espaço, peso, entrelinha e tamanho de ícone vêm da camada 0, e não por tolerância: é assim que o sistema é feito. A diferença é o que cada camada decide. Cor muda de significado conforme o lugar — o mesmo grafite é texto numa tela e fundo de ação em outra, e é a camada 1 que diz qual é qual. Um degrau de espaço não muda de significado: 16px é 16px em toda tela, e dar um nome semântico a ele só acrescentaria um salto para ninguém ler.
