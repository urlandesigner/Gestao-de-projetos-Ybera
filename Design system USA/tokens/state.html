As cores de sucesso, aviso, erro e informação, todas com contraste suficiente para texto sobre branco.

Sucesso, atenção, erro e informação

Os quatro tokens de cada estado

Cada estado tem quatro tokens: texto, fundo, fio e sólido. O texto é o tom 600 e passa AA em letra pequena; o fundo é o 50 e mede só 1.10 a 1.16:1 contra o branco, por isso a caixa tingida leva o fio, que é o 200.

Seleção de texto

Onde a seleção vale

O fundo do trecho que a pessoa seleciona com o mouse ou o dedo. Sem ele, aparece o azul do navegador. Vale só dentro das peças do sistema.

Aa
--yb-selection-bg magenta-300 texto primário a 11:1 sem classe consumidora

Opacidade

Opacidade nunca vai sobre texto

Aplicada a palavra, ela derruba o contraste sem que nada no CSS registre a queda — 5.15:1 a 65% vira 2.9:1, e nenhuma medição do sistema vê. Para texto apagado existe --yb-text-muted, que é medido.

--yb-opacity-control-disabled .45 só superfície e ícone, nunca texto
