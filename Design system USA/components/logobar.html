Logo bar

As sublinhas da marca em faixa escura, entre o conteúdo e o rodapé. Só entra arte monocromática.

  • Classe base .yb-logobar
  • Modificadores 0
  • Elementos 1
  • Estados 0
  • Tokens 5
  • Comportamento só CSS

Como se parece

O branco vem de filtro, não do arquivo

brightness(0) invert(1) achata qualquer arte em branco puro, e é isso que mantém a faixa uniforme quando cada linha entrega um arquivo com peso e cor diferentes. Vale enquanto a arte for monocromática: linha com cor obrigatória pede um segundo arquivo, não um filtro.

Sete logos que não cabem viram rolagem, não fila quebrada

O trilho é overflow-x:auto com a barra escondida. Empilhar as sublinhas em duas fileiras daria a elas o peso de uma seção — e aqui elas são assinatura, não conteúdo.

Em 375px

Viewport de verdade, num <iframe> — e não um quadro estreito. @media consulta a viewport: encolher uma div entregaria a peça fina com o CSS de desktop, que foi como a gaveta do carrinho já apareceu com 222px fingindo estar quebrada.

Anatomia e API

Lido da folha a cada build. Se faltar alguma coisa aqui, falta na folha.

Acessibilidade

  • A faixa é role="group" com aria-label dizendo o que aquela fileira de marcas significa — “as seen in”, “our retailers”. Sem isso são logotipos soltos sem contexto.
  • Cada logo tem alt com o nome da publicação. Aqui a imagem é a informação, ao contrário da foto ilustrativa.

Faça / não faça

✓ Faça

alt="Vogue" · alt="Allure"

Grupo rotulado, cada logo com o nome no alt.

✕ Não faça

alt="" · alt=""

Sem rótulo do grupo e com alt="", a fileira inteira é invisível para quem não a vê.
