Quantity stepper

Botões de 44px, e funcionam — clique. Limites em 1 e 10: o botão desabilita sozinho na ponta.

  • Classe base .yb-stepper
  • Modificadores 1
  • Elementos 0
  • Estados 3
  • Tokens 14
  • Comportamento JS

Como se parece

--sm é exceção, não escolha de gosto

36px em vez de 44. Existe por causa da gaveta: lá o controle divide 420px com foto, título, preço e lixeira, e em 44+48+44 o preço ia para outra linha. O mínimo de alvo do WCAG 2.5.8 (AA) é 24px, então 36 ainda sobra folga — o que se perde é o conforto de 44, que é AAA. Na PDP use o grande: ali o controle antecede a compra.

Em 375px

Viewport de verdade, num <iframe> — e não um quadro estreito. @media consulta a viewport: encolher uma div entregaria a peça fina com o CSS de desktop, que foi como a gaveta do carrinho já apareceu com 222px fingindo estar quebrada.

Anatomia e API

Lido da folha a cada build. Se faltar alguma coisa aqui, falta na folha.

Elementos

Peça de um elemento só: não há partes internas com classe própria.

Marcação

Extraída da primeira demonstração acima — é o mesmo HTML que renderizou ali, não um exemplo escrito à parte.

<div class="yb-stepper" data-yb-stepper>
  <button type="button" data-yb-step="down" aria-label="Diminuir quantidade">−</button>
  <input type="number" value="1" min="1" max="10" aria-label="Quantidade">
  <button type="button" data-yb-step="up" aria-label="Aumentar quantidade">+</button>
</div>
<div class="yb-stepper" data-yb-stepper>
  <button type="button" data-yb-step="down" aria-label="Diminuir quantidade">−</button>
  <input type="number" value="9" min="1" max="10" aria-label="Quantidade">
  <button type="button" data-yb-step="up" aria-label="Aumentar quantidade">+</button>
</div>
<div class="yb-stepper yb-stepper--sm" data-yb-stepper>
  <button type="button" data-yb-step="down" aria-label="Diminuir quantidade">−</button>
  <input type="number" value="1" min="1" max="10" aria-label="Quantidade">
  <button type="button" data-yb-step="up" aria-label="Aumentar quantidade">+</button>
</div>

Acessibilidade

  • É um <input type="number"> de verdade entre dois botões: dá para digitar 12 em vez de clicar doze vezes, e o valor digitado obedece aos mesmos limites.
  • Cada botão tem aria-label próprio (“Decrease quantity”), porque “−” e “+” sozinhos não são nomes.
  • No mínimo e no máximo o botão correspondente recebe disabled — o limite é mostrado, não apenas imposto em silêncio.
  • Os botões declaram type="button": sem isso, dentro de um formulário, cada “+” enviaria o carrinho.

Faça / não faça

✓ Faça

Input real, botões nomeados, limite visível.

✕ Não faça

−1+

Spans com clique: não dá para digitar, não dá para chegar por Tab, e “−” não é nome de controle.
