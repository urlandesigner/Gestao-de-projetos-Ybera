Link

Texto de ação com ícone atrás, do tamanho de alvo de toque (44px). Fica ao lado de um título de seção ou reforça visualmente um link que já existe em outro lugar do mesmo cartão.

  • Classe base .yb-link
  • Modificadores 1
  • Elementos 0
  • Estados 2
  • Tokens 11
  • Comportamento só CSS

Como se parece

Uma receita, escrita duas vezes

.yb-section-head a e .yb-post__link eram o mesmo inline-flex, o mesmo gap, o mesmo alvo de 44px, a mesma cor de link — em dois arquivos diferentes, com peso de fonte e sublinhado que ninguém tinha decidido de propósito. Aqui viraram um componente só.

Base vs. --reinforce

A base é link de verdade: some o sublinhado até o hover, discrição de quem navega. --reinforce é para quando o elemento NÃO é o link — é um <span> ecoando visualmente um link que já existe em outro lugar do cartão (o título, esticado por cima). Por isso fica sempre sublinhado: sem isso não pareceria clicável, e ele parece sem ser.

Em 375px

Viewport de verdade, num <iframe> — e não um quadro estreito. @media consulta a viewport: encolher uma div entregaria a peça fina com o CSS de desktop, que foi como a gaveta do carrinho já apareceu com 222px fingindo estar quebrada.

Marcação

Extraída da primeira demonstração acima — é o mesmo HTML que renderizou ali, não um exemplo escrito à parte.

<a class="yb-link" href="#link">Shop all best sellers <svg class="yb-icon yb-icon--sm" aria-hidden="true"><use href="../icons/ybera-icons.svg#yb-chevron-right"/></svg></a>
<span class="yb-link yb-link--reinforce" aria-hidden="true">Continue reading <svg class="yb-icon yb-icon--sm" aria-hidden="true"><use href="../icons/ybera-icons.svg#yb-arrow-right"/></svg></span>

Acessibilidade

  • O sublinhado é o sinal, não a cor. Link identificado só por cor desaparece para quem não a distingue — e o texto do sistema é escuro sobre claro, onde a diferença de matiz é sutil.
  • O texto do link diz o destino. “Leia mais” repetido cinco vezes na mesma página dá ao leitor de tela cinco links idênticos que vão para lugares diferentes.
  • Ícone dentro do link é aria-hidden="true": a seta não é parte do nome do destino.
