Price

Sempre tabular. Em grid, dígitos precisam alinhar em coluna.

  • Classe base .yb-price
  • Modificadores 2
  • Elementos 2
  • Estados 0
  • Tokens 11
  • Comportamento só CSS

Como se parece

$168.90$199.90Save $31
$133.90 $75.80 $169.70

Em 375px

Viewport de verdade, num <iframe> — e não um quadro estreito. @media consulta a viewport: encolher uma div entregaria a peça fina com o CSS de desktop, que foi como a gaveta do carrinho já apareceu com 222px fingindo estar quebrada.

Anatomia e API

Lido da folha a cada build. Se faltar alguma coisa aqui, falta na folha.

Modificadores

.yb-price--sm .yb-price--stack

Elementos

.yb-price__now .yb-price__was

Estados que a folha trata

Nenhum: o componente não muda de aparência por interação.

Marcação

Extraída da primeira demonstração acima — é o mesmo HTML que renderizou ali, não um exemplo escrito à parte.

<span class="yb-price"><b class="yb-price__now">$168.90</b><s class="yb-price__was">$199.90</s><span class="yb-badge yb-badge--sale">Save $31</span></span>

Acessibilidade

  • O preço antigo vai em <s>, não em text-decoration aplicada a um span. O elemento diz “isto não vale mais”; o estilo só desenha.
  • Preço isolado usa proportional-nums: com tabular-nums o ponto ganha largura de dígito e “$149.90” lê como “$149 . 90”.
  • Quando há desconto, o quanto se economiza está escrito ao lado — dois números riscados não são uma conta que todo mundo faz de cabeça.

Faça / não faça

✓ Faça

$74.90$89.90Save 16%

Preço antigo em <s> e o desconto escrito.

✕ Não faça

$74.90$89.90

Risco só no CSS: para o leitor de tela os dois preços têm o mesmo peso, e o de cima parece o que se paga.
