Form field

Rótulo dentro da caixa, sem uma linha de JS. Erro sempre em texto, nunca só em cor.

  • Classe base .yb-field
  • Modificadores 1
  • Elementos 4
  • Estados 4
  • Tokens 27
  • Comportamento só CSS

Como se parece

Only for order tracking.
Enter a 5-digit ZIP code, like 33101.
Printed on the packing slip, up to 200 characters.
Free shipping over $59.
O rótulo sobe sozinho, sem JS

O input leva placeholder=" " — um espaço. Não é descuido: é o que dá a :placeholder-shown algo em que casar, e é assim que o CSS distingue vazio de preenchido. O <label for> vem depois do campo no HTML, senão o combinador ~ não o alcança — continua sendo rótulo de verdade, clicável e anunciado pelo leitor de tela.

Borda que engrossa sem empurrar nada

O erro e o foco usam box-shadow por dentro, não border-width. Dobrar a borda é mudança de layout: a caixa reflui 1px e o rótulo flutuante, ancorado nela, treme junto. Como pintura, os mesmos 2px aparecem sem mover um pixel do texto.

A mensagem diz como consertar

"Enter a 5-digit ZIP code, like 33101" em vez de "Invalid input". O erro liga ao campo por aria-describedby, então o leitor de tela anuncia a correção junto com o campo — e a borda vermelha nunca é o único sinal.

Em 375px

Viewport de verdade, num <iframe> — e não um quadro estreito. @media consulta a viewport: encolher uma div entregaria a peça fina com o CSS de desktop, que foi como a gaveta do carrinho já apareceu com 222px fingindo estar quebrada.

Acessibilidade

  • Todo campo tem <label> associado por for. Placeholder não é rótulo: some quando a pessoa começa a digitar, exatamente quando ela mais precisa lembrar o que o campo pede.
  • O erro é anunciado por texto, não só por cor: aria-invalid="true" no controle e aria-describedby apontando para a mensagem.
  • A caixa desenha borda e anel de foco; o controle lá dentro fica transparente. Duas bordas concêntricas é o defeito clássico de quem embrulha um input que já tinha a sua.

Faça / não faça

✓ Faça

Enter an address with an @.

Rótulo persistente, erro escrito e ligado ao campo.

✕ Não faça

Placeholder como rótulo: o nome do campo desaparece assim que a pessoa digita, e a borda vermelha sozinha não diz o que está errado.
