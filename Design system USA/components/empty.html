Empty state

Busca sem resultado, filtro que não acha nada, carrinho vazio, produto que saiu do catálogo. Sempre com o próximo passo.

  • Classe base .yb-empty
  • Modificadores 1
  • Elementos 4
  • Estados 0
  • Tokens 11
  • Comportamento só CSS

Como se parece

No results for “keratine”

Check the spelling, or browse the treatments — the shelf is smaller than the search box suggests.

Browse treatments Talk to us

No 3-star reviews yet

Every review this product has so far is a five.

A saída não é enfeite — é o motivo do componente existir

Ausência sem próximo passo é beco: a pessoa chegou onde não há nada e a página não diz para onde ir. Por isso __acoes aparece nos dois exemplos. O ícone fica no tom silencioso do texto de apoio, porque quem precisa ser lido aqui é a saída, não o buraco.

Por que não reaproveitamos o .yb-search__empty

Ele existe desde a busca e continua lá, com o eco do termo digitado dentro. É estado vazio de um componente específico; este é o genérico, que o 404 de produto e o filtro de avaliações usam. Migrar a busca para cá é possível, mas mexeria num fluxo que já funciona — ficou de fora de propósito.

Anatomia e API

Lido da folha a cada build. Se faltar alguma coisa aqui, falta na folha.

Acessibilidade

  • O ícone é aria-hidden="true": ele ilustra a ausência, não a explica.
  • O título entra no nível de heading do contexto em que o bloco mora — dentro de uma seção com h2, ele é h3. Vazio não é motivo para quebrar a hierarquia da página.
  • A ação é obrigatória. Ausência sem próximo passo é beco: a pessoa chegou onde não há nada e a página não diz para onde ir.
