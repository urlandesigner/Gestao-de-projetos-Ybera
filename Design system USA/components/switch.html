Switch

Liga e desliga na hora. Se o efeito só acontece depois de um botão de salvar, o certo é a caixa de seleção.

  • Classe base .yb-switch
  • Modificadores 0
  • Elementos 1
  • Estados 3
  • Tokens 12
  • Comportamento JS

Como se parece

Não é a caixa de seleção com outra roupa

A caixa guarda uma intenção até alguém enviar o formulário; o switch aplica na hora — o seguro de entrega entra no total no mesmo instante. Trocar um pelo outro faz a pessoa procurar um botão de salvar que não existe.

<button role="switch" aria-checked> e não <input type="checkbox">: com o input o leitor de tela anuncia "caixa de seleção, marcada", que promete exatamente o formulário que não há.

O desenho tem 32×20, que é como um switch se lê. O alvo tem 56×44, estendido por um pseudo-elemento — o mínimo da WCAG 2.5.8 é 24×24, e crescer o desenho até lá daria um interruptor do tamanho de um botão.

Em 375px

Viewport de verdade, num <iframe> — e não um quadro estreito. @media consulta a viewport: encolher uma div entregaria a peça fina com o CSS de desktop, que foi como a gaveta do carrinho já apareceu com 222px fingindo estar quebrada.

Marcação

Extraída da primeira demonstração acima — é o mesmo HTML que renderizou ali, não um exemplo escrito à parte.

<button class="yb-switch" type="button" data-yb-switch role="switch" aria-checked="false" aria-label="Seguro de entrega">
  <span class="yb-switch__knob"></span>
</button>
<button class="yb-switch" type="button" data-yb-switch role="switch" aria-checked="true" aria-label="Seguro de entrega, ligado">
  <span class="yb-switch__knob"></span>
</button>
<button class="yb-switch" type="button" data-yb-switch role="switch" aria-checked="false" aria-label="Indisponível" disabled>
  <span class="yb-switch__knob"></span>
</button>

Acessibilidade

  • É <button role="switch"> com aria-checked. Não é checkbox: switch aplica na hora, checkbox espera um “salvar”. O papel diz qual dos dois é.
  • O alvo real tem 56×44 via ::after, maior que o desenho de 44×24 — o gesto no celular acerta a área, não o pixel.
  • O rótulo fica fora do controle, associado por aria-label ou aria-labelledby.

Faça / não faça

✓ Faça

Papel e estado no próprio controle.

✕ Não faça

Div com classe “on”: sem papel, sem estado, sem teclado.
