Certification seals

Faixa de garantia entre a prova social e o rodapé. Diz o que o produto não tem — não é peça de venda.

  • Classe base .yb-seal
  • Modificadores 0
  • Elementos 2
  • Estados 0
  • Tokens 7
  • Comportamento só CSS

Como se parece

Cruelty free
Vegan
Paraben free
Sulfate free
Formaldehyde free
Neutra de propósito

Se a faixa usasse a cor de ação, cinco selos disputariam a mesma atenção que o botão de compra. Garantia sossega; ela não precisa gritar.

O ícone não é a informação

Cada marca é aria-hidden e quem carrega o sentido é o rótulo ao lado — um leitor de tela ouve "Cruelty free", não "imagem". Abaixo de 768 a fileira de cinco vira grade de três: em uma linha só, o texto começava a quebrar em duas.

Em 375px

Viewport de verdade, num <iframe> — e não um quadro estreito. @media consulta a viewport: encolher uma div entregaria a peça fina com o CSS de desktop, que foi como a gaveta do carrinho já apareceu com 222px fingindo estar quebrada.

Acessibilidade

  • A faixa é um role="group" com aria-label: sem o rótulo, o leitor de tela lê cinco palavras soltas sem dizer do que elas são uma lista.
  • O ícone é aria-hidden="true". Quem informa é o texto — “Cruelty free” dito uma vez, não duas.
  • Tom neutro de propósito: se usasse a cor de ação, competiria com o botão de compra pela mesma atenção.
