Logo

O arquivo oficial do header da loja. Vira componente porque aparece em header, footer, e-mail e recibo — e em cada lugar alguém escolhia uma altura diferente.

  • Classe base .yb-logo
  • Modificadores 4
  • Elementos 0
  • Estados 1
  • Tokens 5
  • Comportamento só CSS

Como se parece

Sizes

On dark surface

O alt estava dizendo o nome errado

Em produção o logo do header tem alt="Fashion Gold" — que é nome de uma linha de produto, não da marca. Um leitor de tela anuncia a loja errada logo no primeiro elemento da página. Aqui o padrão é Ybera.

Por que a versão clara é um filtro

O arquivo é monocromático preto, então invert(1) devolve branco puro. Isso não valeria para um logo colorido — se a marca ganhar uma versão em cor, o certo passa a ser um segundo arquivo, não um filtro.

Anatomia e API

Lido da folha a cada build. Se faltar alguma coisa aqui, falta na folha.

<span class="yb-logo yb-logo--lg"><img src="brand/ybera-logo.webp" alt="Ybera" width="360" height="139"></span>

Acessibilidade

  • No cabeçalho o logo é link para a home e precisa de nome acessível: aria-label ou texto escondido. Uma imagem sem alt dentro de um link vira “link, ybera-logo.svg”.
  • Declara :focus-visible e respeita o alvo mínimo — é o primeiro elemento que o teclado alcança na página.

Faça / não faça

✓ Faça

Link com nome acessível, não só a imagem.

✕ Não faça

Sem nome, o leitor de tela lê o nome do arquivo — e o primeiro link da página vira ruído.
