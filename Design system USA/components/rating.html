Rating

Prova social ao lado do preço. Sempre com a contagem: 5 estrelas de 3 avaliações não é prova de nada.

  • Classe base .yb-rating
  • Modificadores 0
  • Elementos 3
  • Estados 0
  • Tokens 9
  • Comportamento só CSS

Como se parece

★★★★★ 4.8 · 412 reviews ★★★★☆ 4.1 · 56 reviews
As estrelas não são texto para o leitor de tela

Elas são aria-hidden e o valor real vive no aria-label. Sem isso, um leitor de tela anuncia "estrela estrela estrela estrela estrela". A cor delas é gold-700, não o dourado de marca — sobre branco o de marca reprovaria.

Em 375px

Viewport de verdade, num <iframe> — e não um quadro estreito. @media consulta a viewport: encolher uma div entregaria a peça fina com o CSS de desktop, que foi como a gaveta do carrinho já apareceu com 222px fingindo estar quebrada.

Anatomia e API

Lido da folha a cada build. Se faltar alguma coisa aqui, falta na folha.

Modificadores

Este componente não tem variantes — o que muda nele vem do conteúdo.

Elementos

.yb-rating__count .yb-rating__score .yb-rating__stars

Estados que a folha trata

Nenhum: o componente não muda de aparência por interação.

Marcação

Extraída da primeira demonstração acima — é o mesmo HTML que renderizou ali, não um exemplo escrito à parte.

<span class="yb-rating" role="img" aria-label="4,8 de 5 estrelas, 412 avaliações">
  <span class="yb-rating__stars" aria-hidden="true">★★★★★</span>
  <span class="yb-rating__count">4.8 · 412 reviews</span>
</span>
<span class="yb-rating" role="img" aria-label="4,1 de 5 estrelas, 56 avaliações">
  <span class="yb-rating__stars" aria-hidden="true">★★★★☆</span>
  <span class="yb-rating__count">4.1 · 56 reviews</span>
</span>

Acessibilidade

  • A nota é role="img" com aria-label escrito por extenso: “4.8 de 5, 128 avaliações”. As estrelas desenhadas são aria-hidden — cinco caracteres “★” lidos em sequência não são uma nota.
  • A nota é link para as avaliações. Nota que não leva a lugar nenhum é beco: quem se interessou pelo número quer o texto por trás dele.
