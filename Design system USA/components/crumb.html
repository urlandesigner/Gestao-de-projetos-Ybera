Breadcrumb

Onde a pessoa está. A página atual não é link.

  • Classe base .yb-crumb
  • Modificadores 0
  • Elementos 0
  • Estados 3
  • Tokens 8
  • Comportamento só CSS

Como se parece

  1. Home
  2. Treatments
  3. Sealants
  4. Fashion Gold

Em 375px

Viewport de verdade, num <iframe> — e não um quadro estreito. @media consulta a viewport: encolher uma div entregaria a peça fina com o CSS de desktop, que foi como a gaveta do carrinho já apareceu com 222px fingindo estar quebrada.

Anatomia e API

Lido da folha a cada build. Se faltar alguma coisa aqui, falta na folha.

Modificadores

Este componente não tem variantes — o que muda nele vem do conteúdo.

Elementos

Peça de um elemento só: não há partes internas com classe própria.

Estados que a folha trata

:focus-visible · :hover · [aria-current]

Marcação

Extraída da primeira demonstração acima — é o mesmo HTML que renderizou ali, não um exemplo escrito à parte.

<nav class="yb-crumb" aria-label="Breadcrumb">
  <ol>
    <li><a href="#">Home</a></li>
    <li><a href="#">Treatments</a></li>
    <li><a href="#">Sealants</a></li>
    <li><span aria-current="page">Fashion Gold</span></li>
  </ol>
</nav>

Acessibilidade

  • A trilha é um <nav aria-label="Breadcrumb"> com <ol> dentro: a ordem é informação, e a lista ordenada é o que a transmite.
  • O último item não é link — é aria-current="page". Link para a página em que já se está é um destino que não leva a lugar nenhum.
  • Declara :focus-visible e respeita o alvo mínimo em cada link.

Faça / não faça

✓ Faça

  1. Home
  2. Fashion Gold
  3. Deep care kit

Último item sem link, marcado como página atual.

✕ Não faça

  1. Home
  2. Fashion Gold
  3. Deep care kit

Último item como link leva a pessoa para onde ela já está — e o leitor de tela não tem como dizer onde ela está.
