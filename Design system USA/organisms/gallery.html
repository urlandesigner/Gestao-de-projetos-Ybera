Gallery

As fotos do produto na PDP: uma foto grande e miniaturas para trocar. Funciona também com teclado e leitor de tela.

  • Classe base .yb-gallery

Como se parece

1 / 5
Sem JS ela ainda troca

O :checked do radio já muda o slide via CSS. O JS só sincroniza o contador e o estado data-active. Se o script falhar, a galeria continua navegável — inclusive por teclado.

No celular

Código

Cada variante sem o cromo da galeria, e o CSS, o JS e os tokens desta peça, lidos da folha a cada build.

Anatomia e API

1 / 5
  1. Container — Palco e miniaturas, ancorados juntos. A troca acontece em CSS, sem script.
  2. Palco — A caixa da foto grande, com a proporção reservada — é o que evita o salto ao carregar.
  3. Foto — Uma por imagem. A ativa leva data-active; as outras ficam no DOM, prontas.
  4. Contagem — “1 / 4”. Diz que há mais foto antes de a pessoa tentar descobrir sozinha.
  5. Miniaturas — Rádios escondidos com <label> em cima: o teclado percorre com as setas.

As peças que formam este componente, o que dá para variar nele e os tokens que ele usa. Tudo é lido direto do código, então está sempre atualizado.

Feita de
Nenhuma outra peça: tudo o que ela desenha sai da folha de estilo dela.
Modificadores
Nenhum. O que muda nela vem do conteúdo.

Faça / não faça

✓ Faça

Miniaturas como input type="radio" + label

Radios nativos: Tab entra no grupo, setas percorrem, e o CSS troca o slide.

✕ Não faça

Miniaturas como <div onclick>

Div com onclick não recebe Tab, não anda com as setas e não diz qual imagem está ativa.

Acessibilidade

  • As miniaturas são um grupo de radio nativo. As setas do teclado navegam entre elas de graça — não há keydown escrito para isso.
  • A foto grande troca por CSS com :checked. Sem JavaScript a galeria continua funcionando; o script só mantém o contador em dia.
  • Cada miniatura tem title e a foto grande tem alt com o nome do produto e o número da imagem — “image 3 de 5” diz onde a pessoa está.
