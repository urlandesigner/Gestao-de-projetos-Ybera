Gallery

A galeria de fotos da PDP: foto grande com miniaturas ao lado. As miniaturas são radios nativos — seta do teclado navega, leitor de tela anuncia.

  • Classe base .yb-gallery

Como se parece

1 / 5
Sem JS ela ainda troca

O :checked do radio já muda o slide via CSS. O JS só sincroniza o contador e o estado data-active. Se o script falhar, a galeria continua navegável — inclusive por teclado.

Anatomia e API

Este bloco não compõe nenhuma peça do sistema, então não há o que apontar. O desenho de um bloco é o mapa dos componentes que ele monta.

De que a peça é feita, o que ela aceita e os tokens que consome — estes do mais específico desta peça para o mais compartilhado com o resto do sistema. Tudo lido da folha de estilo e do HTML a cada build: se estiver errado aqui, o errado é o código.

De que é feitaNenhuma: não consome nenhum outro componente. O que ela desenha sai todo da folha dela.

ModificadoresNenhum. O que muda nela vem do conteúdo.

Elementos.yb-gallery__count .yb-gallery__slide .yb-gallery__stage .yb-gallery__thumbs

Estados que a folha trata:checked · :focus-visible · :hover

ComportamentoPrecisa de ybera-behavior.js. Sem ele renderiza e não responde.

Faça / não faça

✓ Faça

Miniaturas como input type="radio" + label

Radios nativos: Tab entra no grupo, setas percorrem, e o CSS troca o slide.

✕ Não faça

Miniaturas como <div onclick>

Div com onclick não recebe Tab, não anda com as setas e não diz qual imagem está ativa.

Acessibilidade

  • As miniaturas são um grupo de radio nativo. As setas do teclado navegam entre elas de graça — não há keydown escrito para isso.
  • A foto grande troca por CSS com :checked. Sem JavaScript a galeria continua funcionando; o script só mantém o contador em dia.
  • Cada miniatura tem title e a foto grande tem alt com o nome do produto e o número da imagem — “image 3 de 5” diz onde a pessoa está.
