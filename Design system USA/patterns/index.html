O número antes da barra

"Add $12.10 more" diz exatamente quanto falta. Uma barra sozinha obriga a pessoa a estimar, e estimativa não gera compra. A barra tem role="progressbar" com valor real — para quem usa leitor de tela, ela é a única fonte da informação.

Três peças, e não uma folha de página

.yb-page centra e dá a goteira; .yb-block é o ritmo vertical entre seções; .yb-section-head é o par título mais atalho. Separadas porque uma seção que sangra até a borda da tela usa --flush e continua dentro do mesmo ritmo — o carrossel de vídeo é o caso.

O ritmo encolhe no telefone

64px de respiro entre blocos é um oitavo de uma tela de 568px — a PDP levava duas rolagens até o botão de comprar. Abaixo de 768 o respiro cai, e a hierarquia entre --tight e o padrão continua de pé.

Por que isto virou sistema

Regra dos dois usos: home e PDP já pediam os três. Enquanto viviam na folha de cada gerador, toda página nova ia redefinir container e respiro do seu jeito — que é como um design system começa a divergir de si mesmo.

Ybera Design System v0.10 · padrões. Auditado: 0 hex hardcoded, 0 primitivos de cor, 0 referências quebradas. Montado inteiramente com os componentes do sistema — nenhum padrão inventou estilo próprio de botão, card ou preço.
