Textarea

Campo de texto de várias linhas, que cresce conforme a pessoa escreve. Use para mensagens, avaliações e notas de presente.

  • Classe base .yb-textarea

Como se parece

Printed on the packing slip, up to 200 characters.

Estados

Tell us a little about how it worked for you.
Redimensiona só na vertical

resize:vertical: a pessoa pode pedir mais linhas, mas não alarga o campo para fora da coluna. Dentro da caixa nasce com 72px, porque o rótulo já ocupa o topo; solto, com 96px.

O rótulo sobe para o topo, não para o meio

No Input o rótulo descansa no centro da caixa; aqui ele descansa na primeira linha, que é onde a pessoa vai começar a escrever. Mesmo mecanismo, sem JS: placeholder=" " e :placeholder-shown.

Anatomia e API

Printed on the packing slip, up to 200 characters.
  1. Campo — A mesma caixa do Input, com o controle de várias linhas dentro.
  2. Controle — Redimensiona só na vertical: esticar na horizontal quebraria a coluna de leitura.
  3. Rótulo — Flutua como no Input, pela mesma mecânica de placeholder com um espaço.
  4. Moldura — Onde o rótulo flutua, igual ao Input — e onde a alça de redimensionar aparece.
  5. Dica — Opcional. Bom lugar para o limite de caracteres, quando houver.

As peças que formam este componente, o que dá para variar nele e os tokens que ele usa. Tudo é lido direto do código, então está sempre atualizado.

Faça / não faça

✓ Faça

Campo com nome e altura que cabe a resposta esperada.

✕ Não faça

Input de uma linha para texto livre: a pessoa escreve às cegas, vendo só o fim da frase.

Acessibilidade

  • Sempre com nome, como o Input.
  • Se houver limite de caracteres, diga o limite antes e conte enquanto a pessoa digita — descobrir o corte depois de escrever é o erro mais caro.
  • Erro em aria-invalid="true", com a mesma borda e o mesmo ícone do Input.
