Badge

Etiqueta curta que informa algo sobre um item, como “In stock” ou “−16%”. Não é clicável: para uma ação, use o Button.

  • Classe base .yb-badge

Como se parece

Variants

Save 16% --sale New --dark Members only --secondary Best seller --soft In stock --success Low stock --warning Sold out --danger

On dark surface

New line --on-media Limited --sale 10k+ routines created --on-dark
Nenhum selo claro serve sobre foto

O --secondary foi testado nos selos de brinde do cartão de produto, que ficam sobre o packshot, e reprovou: medido nas fotos reais, o chip cai para 1,2:1 contra a foto e o texto para 3,78:1 — abaixo de AA. Fundo claro deixa de isolar o texto, e quem decide a leitura passa a ser uma foto que ninguém controla. Sobre foto, use --on-media (12,6:1 nas mesmas fotos) ou --sale. Os claros — --secondary, --soft, --success, --warning, --danger — são para superfície lisa.

--sale grita, --secondary rotula

O --sale é o magenta cheio do sinal (--yb-accent-signal): desconto é marca que precisa ser vista antes de ser lida. O --secondary usa os mesmos tokens do botão secundário, contorno preto, e rotula sem disputar com o preço ao lado. Um por contexto — dois selos cheios na mesma linha voltam a empatar a leitura.

O magenta sobre escuro não é o magenta canônico

--on-media escreve em --yb-accent-signal-on-dark, que mede 6,49:1 sobre o grafite. O magenta canônico foi escolhido para ler sobre branco e cai para 3,11:1 ali. Nenhuma cor é escura o bastante para o branco e clara o bastante para o grafite — por isso o contexto está no nome do token.

Anatomia e API

Save 16%
  1. Etiqueta — Rótulo estático, não é botão. A variante dá a cor; o texto diz o quanto, não a palavra “promoção”.

As peças que formam este componente, o que dá para variar nele e os tokens que ele usa. Tudo é lido direto do código, então está sempre atualizado.

Feita de
Nenhuma outra peça. Um átomo não usa outros componentes — é isso que faz dele átomo.

Save 16% →

Badge com link vira um alvo de 20px que parece rótulo. Quem navega por teclado encontra um foco onde não esperava clique.

Acessibilidade

  • Badge não é botão: não recebe href, onclick nem foco. Se o rótulo precisa levar a algum lugar, o componente certo é outro.
  • O texto é quem informa. Não existe badge que comunique só por cor — “Sold out” diz o que a cor sozinha não diria a quem não a distingue.
  • O dourado (--accent) vive só sobre superfície escura: mede 6.96:1 lá e 2.39:1 sobre branco, que reprova.
