Uma receita, escrita duas vezes

.yb-section-head a e .yb-post__link eram o mesmo inline-flex, o mesmo gap, o mesmo alvo de 44px, a mesma cor de link — em dois arquivos diferentes, com peso de fonte e sublinhado que ninguém tinha decidido de propósito. Aqui viraram um componente só.

Base vs. --reinforce

A base é link de verdade: some o sublinhado até o hover, discrição de quem navega. --reinforce é para quando o elemento NÃO é o link — é um <span> ecoando visualmente um link que já existe em outro lugar do cartão (o título, esticado por cima). Por isso fica sempre sublinhado: sem isso não pareceria clicável, e ele parece sem ser.
