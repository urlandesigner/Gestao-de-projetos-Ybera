Atoms

As peças mais simples, que não usam nenhuma outra: botão, campo, selo, estrelas.

A regra do degrau: Não usa nenhuma outra peça do sistema. Se você tirar qualquer parte dele, ele deixa de funcionar.

Atoms 19

Avatar Círculo com a inicial de quem está logado. Aparece no cabeçalho e no menu da conta, sempre junto do nome da pessoa. Badge Etiqueta curta que informa algo sobre um item, como “In stock” ou “−16%”. Não é clicável: para uma ação, use o Button. Button Botão que executa uma ação, como comprar ou continuar. Use só um botão primário por tela; as outras ações ficam no secundário ou no ghost. Certification seals Ícones com o que o produto não contém, como “Formaldehyde-free”. Ficam numa faixa de garantias perto do rodapé. Checkbox Caixa que a pessoa marca ou desmarca. Use quando cada opção vale sozinha e dá para marcar várias, nenhuma ou todas. Chip Botão pequeno de filtro, que liga e desliga, usado em fileira acima de uma lista. Quando está ativo, muda de aparência. Icon button Botão quadrado de 44px só com ícone, como fechar, buscar ou favoritar. Precisa de um nome para leitor de tela, porque não tem texto visível. Input Campo de texto de uma linha, com o nome do campo dentro da caixa. Use para nome, e-mail, CEP ou senha; dica e erro aparecem embaixo. Link Texto clicável que leva a outra página, com uma seta ao lado. Use ao lado do título de uma seção, como “Shop all”. Logo A marca Ybera, em um arquivo só, com alturas prontas para cabeçalho, rodapé e e-mail. Notice Faixa fina de aviso no topo da página, na largura toda. Use para recados da loja, como o frete grátis. Offer seal Selo em forma de estrela sobre a foto do produto, para destacar brinde ou desconto. Use no máximo um por produto. Progress bar Barra que mostra quanto de algo já foi concluído. Use quando dá para medir o andamento; quando não dá, use a versão sem número. Radio Lista de opções em que só uma pode ser escolhida. Use quando são poucas opções e todas devem ficar visíveis; para muitas, use o Select. Select Campo que abre uma lista para escolher uma opção. Use quando as respostas possíveis já são conhecidas, como estado ou país. Skeleton Bloco cinza que ocupa o lugar do conteúdo enquanto ele carrega. Use só enquanto o conteúdo está de fato chegando. Stars As cinco estrelas da nota, preenchidas de acordo com um número de 0 a 5. Sozinhas mostram a nota de uma avaliação; dentro do Rating, a média. Switch Interruptor que liga ou desliga uma opção na hora. Se a mudança só vale depois de clicar em salvar, use o Checkbox. Textarea Campo de texto de várias linhas, que cresce conforme a pessoa escreve. Use para mensagens, avaliações e notas de presente.
